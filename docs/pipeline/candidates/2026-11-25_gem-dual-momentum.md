# GEM 듀얼 모멘텀 (SPY / 해외 / 채권) — 월 1회
- 출처/공개일: Antonacci, "Dual Momentum Investing" (2014). 이후가 진짜 OOS. 출처 주장(미검증): 1974–2013 CAGR 약 17%, vol 약 12%, MDD 약 -22%.
- 가설: 상대모멘텀(미국 vs 비미국) + 절대모멘텀(vs 단기채)로 약세장은 채권으로 이탈. 회전율 낮고 레버리지 없음 → 추세(TQQQ)·고베타 계열과 상관 낮음.
- 규칙: 월 마지막 거래일 종가 t에서 12개월(252거래일) 총수익률 계산. SPY 12m > BIL 12m 이면 위험자산, 아니면 100% AGG. 위험 보유 시 SPY vs ACWX 12m 큰 쪽 100%. 체결 t+1 정규장 금액매수. 신호 불변이면 주문 없음. 룩백은 12m 고정(6/9m 민감도는 별도 아이디어로 내지 않고 강건성 점검용으로만).
- 수단/데이터: SPY(1993), ACWX(2008-03), AGG(2003), BIL(2007) 일봉(수정종가). 토스 일봉·키 없는 소스 가능. 일봉만으로 포워드 가능.
- 실계좌 가능성: 비레버리지, 소액 금액매수 가능.
- 회전율/비용: 연 1~2회 전환 예상(출처 주장). 전환당 왕복 약 0.2% + 환전 0.05%(평일 09:00–15:30 KST 한정; 야간 0.5%면 악화) + 매도 SEC/TAF 최소 $0.01(소액 시 수십 bp). 거래당 필요 엣지 약 0.3~0.8%.
- 비판/과최적화: 2010년대 이후 성과 둔화 보고, 룩백·월말 선택 임의성, 이탈 지연, 인상 국면에서 AGG 동반 하락 위험.
- 현 레짐 근거: 나스닥 조정 + 금리 인상 우려에서 SPY 12m이 BIL 밑이면 채권 전환으로 낙폭 방어. 현재 12m 수익이 아직 양(+)일 가능성이 있어 즉시 발동은 불확실.
- 킬 기준: 포워드 n>=60 거래일에서 z<-2 또는 MDD가 QQQ B&H 초과.
- 레인: 1 (위험조정)
