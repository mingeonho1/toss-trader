### D8. R3 / U4(iii) / M2 사전등록
- R3 결론(감사 WEAKENED)을 받아들인다. DEMOTED 8종 중 6종의 z_M2는 −2 위다. 반면 basket과 simple은 같은 곡선이고 경계 GENUINE(−2.17/−2.22)이다. hibeta 6종은 실질적으로 독립 흐름 약 1.4개다.
- **정직 표기**: 사전등록한 주 지표는 M1(선형)이었다. M1은 대조군 tqqq_bh를 −3.98로 오판했고, 그래서 결과를 본 뒤 M2(2차항)로 교체했다. 이 교체로 buffer_hibeta와 lrs200_tqqq가 GENUINE에서 BETA/REGIME로 바뀌었다. 즉 전략에 유리한 방향의 교체다. M1 기준이었다면 이 두 전략은 퇴출 쪽이다.
- **M2 진단 사양 동결(오늘, 결정권자 권한 = 진단 사양이며 규칙이 아님)**: 주 지표는 z_M2 = (X − M2 기대 X)/(σe_bt·√m)이다. 모형은 r_s = a + b·r_q + c·r_q², 백테스트 창은 2021-01-01~2026-09-28, 곡선은 R2 재생 곡선이다. GENUINE은 z_M2 ≤ −2이면서 JK max ≤ −2일 때다. 대조군 tqqq_bh의 |z_M2| ≥ 2이면 진단 전체를 무효로 한다. M1, M3, liveσ, z_vol은 보조 지표다. 이후 사양 변경은 날짜 부록으로만 한다.
- **U4(iii) 권고(사용자 승인 필요)**: **"판정 연기"로만 찬성한다.** R3-b(12-15 세션)에서 z_M2 > −2이면 RETIRED를 n=63까지 미룬다. n≥63부터는 원래 규칙(excess −15% 하드 플로어 포함)을 그대로 적용한다. 연기의 비용은 약 3주 관찰 연장뿐이고 돈은 걸려 있지 않다. 승인되면 `decision_rules.md` 날짜 부록에 "결과 관측 후 제안 + 모형 사후 교체"를 명시한다. 승인이 없으면 상태기계대로 12-23에 퇴출한다(D7이 확인되면 주석을 붙임).
