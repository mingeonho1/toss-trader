## 0. 메커니즘 (왜 이게 새로운가)

수수료는 **노셔널(거래대금)의 %** 다(토스 US 표준 25bp/side). 따라서 **노출(exposure) 1단위**를 얻는 데
드는 수수료는 어떤 배수의 ETF로 사느냐에 달려 있다.

- 1x(QQQ)로 노출 $E → 노셔널 $E → 왕복 수수료 = 2·c·E.
- 3x(TQQQ)로 **같은** 노출 $E → 노셔널 $E/3(델타 3배) → 왕복 수수료 = 2·c·(E/3) = **1/3**.

즉 **동일한 시장 노출을 1/3 노셔널로 사면 노출당 수수료가 1/3로 압축**된다. 1x에서 총엣지 ≈ 왕복비용이라
순엣지 0 인 신호(예: c2b RSI(2), 총 +0.62%/거래 = 왕복 62bp)는, 3x·1/3노셔널로 집행하면 왕복비용이
≈21bp로 떨어져 **순엣지가 양(+)으로 전환될 수 있다.** 대가는 3x의 **경로 손실(vol decay)·경비·차입비**인데,
보유가 1–5일로 짧으면 감쇠는 작다 — **측정 대상**이다.

**핵심 항등식(노출당, 단위노출 E=1)**: 3x·(1/3노셔널) 집행의 노출당 손익
 = 기초 총수익 R − (경로감쇠 = (k²−k)/2·Σσ²_일 = 3·Σσ²_일) − (경비+차입)·보유일/252·(1/3)·3
 vs 노출당 왕복 수수료 (2/3)·(c+반호가₃ₓ+슬리피지) = 1x의 62bp 대신 **≈21.3bp**.
따라서 Δ(순엣지) ≈ (1x왕복 − 3x왕복)/노출 − 경로감쇠 ≈ (62 − 21.3)bp − decay = **+40.7bp − decay**.
decay 가 40bp 미만이면 순엣지가 양(+)으로 뒤집힌다. **decay 를 거래별로 실측**해 이 판정을 데이터로 한다.

## 1. 사전등록 설정 (실행 전 고정 — 아이디어당 1개 + 평탄성 이웃)

**공통**: 신호 = NDX **가격지수** 종가 기반(RSI) 또는 **스케줄 캘린더**(TOM/FOMC). 실행 = NDX-TR(1x, 배당 0.7%/yr)
+ 합성 TQQQ(3x, DTB3 차입 + 0.5% 스프레드 + 0.95% 경비, `histdata.synthetic_leveraged`). **슬리브 현금수익률 0%**
(v2.1 §2 기본; DTB3 는 민감도로만). 비용 = 25bp/side + 반호가(ETF 1bp·레버리지 2bp) + 슬리피지 5bp, FX 는 입금에만.
벤치마크 = **QQQ 100% = NDX-TR 1x B&H(단위자본)**.

c2c 의 pre-FOMC FAIL 을 **비용압축 메커니즘으로 구제 가능한지**를 직접 시험한다.

**평탄성 이웃(±grid, 설계기간·원장 적재)**: `rsi_entry∈{5,7,8,12,15}`, `notional_frac∈{0.25,0.30,0.40,0.50}`,
`sma_exit∈{3,4,6,8}`(RSI 계열), TOM `(n_end,n_start)∈{(1,2),(1,4),(2,3)}`. 그리드서치 아님(사전등록 1설정의 강건성만).

**분할(peek-once)**: 설계 1986–2008(닷컴·GFC 포함) / **홀드아웃 2009–2026**. 실물 QQQ/TQQQ 2016–2026 은 확인용.

**체결 규약(모호성 해소, README §8 명시)**: 전 백테스트 `exec_lag=1`(신호 종가 t → 체결 t+1 종가, README §4).
- 가격신호(RSI): c2b 와 **동일 규약**(신호 close t, 체결 close t+1) — 메커니즘 비교가 c2b rsi2 1x 와 apples-to-apples.
- 캘린더신호(TOM/FOMC): 스케줄이 **사전 고지**되므로 "이벤트일 전날 종가에 포지션"이 현실적 체결이다.
  이를 `capture(next_trading_day∘next_trading_day(date[t]))` **순수 date 함수**로 구현 → 배열 미래참조 없음
  (prefix invariance), 이벤트일 수익을 exec_lag=1 하에서 정확히 담는다. 단일일 pre-FOMC 도 이 방식으로 포착.

**신호 재사용 페널티(v2.1 §4)**: RSI2·TOM·pre-FOMC 는 c2b/c2c 에서 이미 홀드아웃을 봤다. 새 idea_id 를 쓰되
홀드아웃을 **"반오염(semi-contaminated)"** 으로 표기하고 통과 기준을 **RC/SPA p < 0.01** 로 강화한다.

**다중검정(v2.1 §3)**: DSR 의 N 은 **프로그램 전체 원장 N**(아이디어 간 포함)으로 계산해 함께 보고(아이디어 내부 N 은 참고).

**리스크(v2.1 §1)**: NDX 1x(벤치) 자체가 설계구간 MDD ≈ −83% 로 −50% 절대캡을 구조적으로 위반 →
**상대리스크 트랙**: `MDD_s ≥ MDD_b − 5%p` 그리고 `Ulcer_s ≤ 1.10·Ulcer_b`(설계·홀드아웃 모두).
레버리지 사용 계열은 추가로 **전표본 MDD_s ≥ −70%**(파산 방지 하한).

**코어-위성 평가(v2.1 §5)**: 위성(#1,#2,#5)은 단독이 아니라 **코어(QQQ)+위성 포트폴리오 vs QQQ 100%** 로도 판정
(위성이 현금에 머무는 **기회비용 포함**). #3,#4 가 그 포트폴리오 판정이다.

**측정(사전 명시)**: 거래별 (a) 1x 총엣지, (b) 실현 3x 경로감쇠 = TQQQ실현 − 3·기초, (c) 25bp·10bp 노출당 순엣지,
(d) 거래 t(gate.trade_tstat)·부트 CI(gate.trade_pnl_bootstrap_ci)·n. 포트폴리오: CAGR/Sharpe/MDD/Ulcer/Calmar,
DSR(내부+프로그램 N)·RC/SPA p, v2.1 상대리스크, 비용 2× 스트레스, 10bp what-if — vs QQQ 100%.

## 2. 방법 메모 (정직성)

- **합성 TQQQ 신뢰도**: `validate_synthetic`(2016–2026 겹침) 결과 일수익 **상관 0.9991**, 연추적차 +0.05%,
  CAGR 합성 41.14% vs 실물 41.96%. 장기(pre-2010) 합성은 여전히 **모델**(저신뢰 라벨, 사양 §5.2)이나
  실물 검증구간에서 충실도가 높아 메커니즘 결론의 신뢰를 받침.
- **exec_lag=1 의 RSI 처리**: c2b §5 에서 RSI(2)는 MOC(신호봉 체결)와 t+1 체결이 사실상 동일(exp −0.03% vs +0.00%)
  임이 확인됨 → 체결규약이 결론을 만들지 않는다.
- **경로감쇠 부호**: RSI2 진입은 과매도 후 반등(상방 추세)이라 3x 복리 볼록성이 분산드래그를 일부 상쇄할 수 있다 —
  순 감쇠는 **거래별 실측**으로만 판정.
- **결정론적·키리스**. lookahead_guard 를 **모든 신호**에 적용(tests/test_c3b.py). src/ 미수정(소비만).

## 3. 결과 — 메커니즘은 실재(거래별 유의), 채택은 전부 FAIL

> **한 줄 결론: 비용압축 메커니즘은 데이터로 입증됐다.** 3x·1/3노셔널 집행은 RSI2 의 거래별 순엣지를
> 1x 의 **+0.0bp(t=0.00)** 에서 **+33.0bp(t=2.45, CI[+7.8,+57.3])** 로, 이벤트 union 을 +1.2bp(t=0.12)에서
> **+36.0bp(t=3.57, CI[+16.1,+55.9])** 로 뒤집는다. 그러나 **어떤 config 도 QQQ 100% 를 이기지 못하고**(홀드아웃
> 최종/QQQ 전부 <1), 상시투자 부스트(#3,#4)는 닷컴·GFC 전표본 MDD −84%/−89% 로 **−70% 파산하한을 위반**한다.
> DSR(프로그램 N=396)은 전 config 0.00, RC/SPA p ≫ 0.01. **아이디어 가족 5개 전원 FAIL, 채택 0건.**

  이론치, 실측 +33.0bp(부트 우측). 어느 쪽이든 **순엣지가 0 → 양(+)유의로 전환**. 메커니즘 실증.
- **감쇠는 예측대로 작다**: decay ∝ 보유일×분산. 3.6일 보유 −23bp, **1일 pre-FOMC −2.7bp**(거의 0). 단일일
  이벤트가 비용압축의 가장 순수한 적용임을 확인(pre-FOMC 1x −24.9bp → 3x·⅓ +14.8bp).
- **실물 QQQ/TQQQ 2016–2026 확인**: 동일 방향(부호 일치). rsi2 1x −12.2bp → 3x·⅓ +20.0bp(t=1.03),

  상관 0.9991, 연추적차 +0.05%, CAGR 41.14% vs 실물 41.96%.

**축별 해석**:
1. **경제(vs QQQ 100%) — 전 config FAIL.** 슬리브(#1,#2,#5)는 현금대기 기회비용이 거래별 엣지를 압도(tv/QQQ
   0.04–0.10). 코어-위성(#3)은 15% 가 현금(0%)에 머무는 드래그로 tv/QQQ 0.82. 상시부스트(#4)조차 0.97(<1) —
   이벤트 부스트의 순이득이 닷컴·GFC 의 부스트 손실을 못 메운다(설계 tv/QQQ 0.69). **v2.1 §5 기회비용 판정의 정확한 사례**.
2. **다중검정 — 전 config FAIL.** 프로그램 N=396 에 대해 DSR 0.00, RC/SPA p 0.66–1.00 ≫ 0.01(반오염 강화임계).
   거래별 t 는 높아도(3.57) **QQQ 대비 일별 초과수익 스트림**은 유의하지 않다(슬리브는 대부분 현금이라 강세장에서 열위).
3. **리스크 — 상시투자 계열 FAIL.** 슬리브(#1,#2,#5)는 상대리스크 통과·파산하한 준수(MDD −21~−43%). 그러나
   코어-위성·부스트는 벤치(QQQ)가 이미 −83% 인 구간을 3x 로 물려 전표본 −84~−89% → **−70% 하한 위반**.
4. **비용 강건성**: 10bp 프로모 what-if(홀드아웃 tv/QQQ)조차 슬리브는 0.04–0.14, 부스트는 0.94–1.05 로 여전히 QQQ 미달·경계.
   2× 스트레스도 동일 결론. 비용이 아니라 **기회비용·레버리지 리스크**가 벽이다.
5. **부스트 노출-일당 커미션(결정론적)**: config4(QQQ↔TQQQ 스왑) **16.8bp**, config3(현금↔TQQQ) **5.7bp**.
   config3 가 커미션은 싸나(단일자산·소노셔널) 15% 현금 기회비용을 지고, config4 는 커미션은 비싸나(2자산 왕복)
   기회비용 0 — **"압축된 커미션 vs 기회비용"의 트레이드오프**를 정량화. 둘 다 순이득으론 QQQ 미달.

### 3c. gate.decide 종합 · 정직한 해석

| config | 경제 | 유의성 | 리스크 | 종합 |
|---|---|---|---|---|
| c3b_lcc_rsi2 / events / prefomc (슬리브) | FAIL(tv/QQQ<1) | FAIL(p≫0.01) | PASS(상대리스크·하한) | **FAIL** |
| c3b_core_sat / core_boost (상시) | FAIL(tv/QQQ<1) | FAIL(p≫0.01) | FAIL(−70% 하한 위반) | **FAIL** |

1. **메커니즘은 진짜다(과적합 아님).** 비용압축은 회계 항등식이고, RSI2·events 거래별로 t=2.45–3.57·CI 우측·
   실물 재현으로 확인됐다. "1x 에서 죽는 저엣지 신호를 3x·⅓ 로 살린다"는 명제 자체는 **참**이다.
2. **그러나 거래별 엣지 ≠ 채택 가능한 전략.** (a) 슬리브는 현금대기 기회비용이 엣지를 삼키고(강세장 QQQ 미달),
   (b) 상시투자로 기회비용을 없애면(#3,#4) 이벤트 부스트가 **대폭락에서 3x 로 물려 −70% 파산하한을 깬다**.
   비용을 압축해도 **QQQ 100% 를 이기는 배치가 없다** — 게이트가 정확히 이 함정을 잡아냈다.
3. **pre-FOMC 단일일**은 감쇠가 사실상 0(−2.7bp)이라 메커니즘엔 최적이지만, 연 8회·in-market 2.5% 라 포트폴리오
   기여가 미미(tv/QQQ 0.04). 비용압축이 **작은 이벤트를 net+ 로 만들 순 있어도 규모를 만들지 못한다**.
4. **다음 루프 함의(승격 아님)**: 이 계열을 되살리려면 (a) 기회비용 없이 노출을 채우면서(항상 1x) 부스트만
   압축 집행하되 **대폭락 노출을 차단하는 추세/변동성 게이트**를 얹은 새 idea_id, 또는 (b) 커미션이 더 낮은
   체제(프로모 10bp에서도 부스트 tv/QQQ 0.94–1.14 경계)가 필요. 본 사이클 채택 0건.

**운영 결론: c3b 가족 채택 0건.** 소액 슬리브·포워드 페이퍼 승격 후보 없음. B0(QQQ60/SCHD25/GLD15)·B1(QQQ) 유지.
비용압축은 **입증된 메커니즘으로 문서화**하되(향후 재사용 가능), 단독 채택 근거는 아니다.
