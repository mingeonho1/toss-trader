## 최종 판정: **WEAKENED**(약화 — 반증되진 않았으나 3.11× 서사가 붕괴하고 glide 에 열위)

사전등록 규칙(median≥1.15×B1 AND p5≥0.9× AND regret 증가≤5pp, **20년 지평**)은 배당정정·
정직한 코호트-ATH 정의에서도 **설계 20y 만 아슬하게 유지**(1.20×)된다. 따라서 crash_lev 는
반증(REFUTED)되진 않는다. 그러나 c6c 가 내세운 강한 주장은 전부 깨진다:

1. **홀드아웃 3.11×(정정 후 2.82×)는 인공물이다.** (a) c6c 는 낙폭을 **패널 전역 running-max
   = 시장 ATH** 로 재므로 2000–2006 코호트를 '이미 −60% 인 시장'에 태워 시작부터 QLD 로 라우팅한다.
   신선한 투자자의 정직한 **코호트-ATH**(자기 시작일 기준)로 바꾸면 홀드 2.82× → **1.78×** 로
   내려앉는다(설계는 1.20× 불변 — 설계 코호트는 시작이 곧 고점이라 무영향). (b) 종점 절단
   민감도: 20y 홀드 자연종점(2020–2026 고점) 2.80× 가, 종점을 **2009 GFC 저점**에 두면 **0.45×**
   로 역전한다. 단일 최심 코호트(2000-03) 비는 종료연도에 **단조**로 0.49×(2009)→3.06×(2026) —
   3.11× 는 **데이터가 시클리컬 고점에서 끝난다는 사실**의 산물이다. (c) 20y 홀드는 시작 2000–2006
   뿐(닷컴→2021 슈퍼사이클 **단일 매크로 에피소드**, 겹침 시작일) → 유효 독립표본 ≈1.

2. **정직한 부트스트랩(경로상대 ATH)의 실제 우위는 ~1.1× 에 불과하다.** 20y median **1.10×**,
   P(<B1)=**0.22**, P(<0.9)=0.10, CVaR5 **0.64** — median 조차 1.15× 문턱 아래다(정직 검정에서는
   설계 PASS 도 확정적이지 않음). 10y 는 median 1.01×(사실상 무우위).

3. **레짐 취약성 — Nikkei 잃어버린 10년이 '일반적 안전'을 반증한다.** crash_lev 의 핵심 규칙은
   낙폭이 **깊고 오래 갈수록 QLD 로 더 많이** 태우는 것인데, 지수가 사상최고를 영영 못 되찾으면
   이는 정확히 **손실 증폭 장치**가 된다. Nikkei 20y·10y 설계·홀드 **전부 FAIL**(10y 홀드 0.67×·
   regret **0.63**, 20y 홀드 0.91×·regret 0.23), 원장 홀드아웃 **단위 MDD −98%**. glide 의 Nikkei
   홀드(0.97×)보다도 **더 나쁘다** — crash_lev 는 메커니즘상 이 레짐에 더 노출된다.

4. **glide 에 파레토 열위 — '3.11×' 매력은 착시였다.** 같은 정직한 부트스트랩 경로에서 crash_lev
   는 median 1.10× / P(<1) 0.22 / CVaR5 0.64, glide 는 **1.39× / 0.09 / 0.83** — glide 가 median·
   하방·꼬리 **모든 축에서 우월**하다(§8, 이득/위험 0.27 vs 2.33). 게다가 두 전략 상대성과의
   상관은 부트스트랩 **0.14**(사실상 무상관), 역사 설계 코호트에선 **−0.78**(반대!) — **같은 베팅이
   아니다**(glide=초기 생애 레버리지, crash_lev=낙폭조건부 기회 레버리지, 경로의 다른 국면을 태움).
   즉 crash_lev 를 glide 대신 채택할 이유가 없다.

5. **행동재무(B1 대비 정정).** '−80% 낙폭'은 1x 기준선을 병기해야 뜻이 산다: 20y **홀드아웃**
   crash_lev 최악 달러낙폭 −0.81 **vs 같은 경로 B1 −0.52**(레버리지 순증분 ~−29%p, crash_lev 최악
   시점에 B1 은 −0.52). 반면 **설계** 코호트는 crash_lev −0.82 **vs B1 −0.81** — 닷컴·GFC 를 큰
   잔고로 통과하는 설계 코호트는 **1x DCA 자체가 −81%** 라 레버리지 순증분이 ~0 이다. 두 코호트
   모두 P(달러낙폭>50%)=**1.00**(B1 도 설계 1.00·홀드 0.93). README §7 −50% 하드캡·게이트 부록
   v2.1 §447 레버리지 **−70% 파산하한을 위반**(홀드 단위 MDD −98%).

## A. 코드 리뷰 (experiments/c6c_contrib.py, crash_lev 경로)

- **look-ahead: 통과.** 낙폭신호 `drawdown_series` 는 running-max·단조감소큐(52주)로 **인과적**,
  히스테리시스 상태 `in_lev` 는 t 이하만 참조. `make_signal_fn`+`lookahead_guard`(음성대조 포함)
  및 본 감사 `test_c7a.test_crashlev_no_lookahead` 재확인.
- **"ATH" 정의: 시장 ATH(코호트 아님) — 낙관 편의의 핵심.** `add_signals` 가 dd_ath 를 **패널
  전역** QQQ running-max 로 계산 → 코호트가 겪지 않은 과거 고점 대비 낙폭을 신호로 씀. 2000–2006
  코호트는 시작 시점 시장이 2000 고점 대비 −40~−60% 라 **첫 적립부터 2x 라우팅**된다. 이는 look-ahead
  는 아니나(과거만 참조) 신선한 투자자의 실경험과 다르다. 정직한 코호트-ATH 변형을 구현·대조(§1):
  홀드 2.82×→1.78×. **부트스트랩 MC 는 경로 자기 running-max(=코호트/경로 상대)를 쓰므로 이
  인공물이 제거된 정직한 검정이다(§2).**
- **체결 타이밍(경미).** 월초 종가 결정·체결(exec_lag=0), README §4 t+1 규약과 어긋나나 dd_ath 는
  느린 상태신호라 1일 지연 영향은 미미. 잔여 리스크로만 기록.
- **수수료: 합리적.** 매수 ≤$10 분할 무료, crash_lev 는 **무매도**라 매도수수료 없음, FX 20bp 는
  신규 입금에만. 케이던스상 총비용 <0.1%/yr.
- **합성 2x 배당 이중계상: 실재(정정함).** c6c 의 QLD 는 총수익 base 에 2x → 배당 2배(−0.7%/yr
  과대, 레버리지 구간 전체). c6a 정정(2×가격+1×배당)을 전 패널·OOS·스트레스에 적용. 정정 후에도
  설계 20y 1.20× PASS(레버리지 노출이 상시가 아니라 낙폭구간 한정이라 median 영향 ~1–3%p).

## B. 스트레스·강건성 요약

- **조달 +2%: 설계 1.11× → FAIL**(glide 는 1.28× PASS). 설계 20y 우위가 **조달비용에 취약** —
  glide 대비 얇은 마진. 보수 1.5% 는 1.17× PASS(견고).
- **5년 후 적립중단(실직): 중립**(최종비 median 1.00, P(<B1) 0.26) — 더 나빠지지 않음.

## C. 안전 채택 권고 (사전등록 규칙에서 도출 — 재튜닝 아님)

1. **glide 가 있으면 crash_lev 를 택하지 말 것.** 정직한 검정에서 median·하방·꼬리 전부 열위,
   무상관이라 분산효과도 제한적. crash_lev 단독 매력(3.11×)은 종점·시장ATH·단일에피소드 인공물.
2. 굳이 쓴다면 **소액 슬리브 + 20년+ 지평 + 조달비용 여유 확인 + 잃어버린10년 킬스위치**(1x 슬리브
   롤링 10년 실질수익이 (−)면 신규 2x 라우팅 중단) 하에서만. 단위 MDD≈−0.98·달러낙폭>50% 확정은
   §447 −70% 하한·README §7 −50% 캡 위반 → 전량 금지.
3. **필수 고지.** (i) 홀드 3.11× 는 재현 불가한 인공물, 정직한 기대는 ~1.1×; (ii) 성과는 장기
   (+)주식프리미엄+시클리컬 고점 종료에 의존(일본 반례); (iii) 합성·소표본 낙관 → 포워드 페이퍼 후에만.
